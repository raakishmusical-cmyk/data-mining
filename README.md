# Data Mining Project

## 📌 Overview

This project is a Python-based data mining and web scraping application that collects business information and exports the results to CSV files.

### Features

- Scrapes business data dynamically
- Validates mobile and phone numbers
- Handles duplicate records
- Generates CSV output automatically
- Optimized for large datasets

---

## 🛠️ Technologies Used

- Python 3.12+
- Playwright
- Pandas
- OpenPyXL
- AsyncIO

---

## 📂 Folder Structure

```text
Data-Mining/
│── Mining_Data.py
│── requirements.txt
│── .gitignore
│── README.md
└── Output/
```

---

## ⚙️ Process to Get the Output

### Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run the Project

```bash
python Mining_Data.py
```

The generated CSV files will be saved in the `Output` folder.

---

## 📋 Requirements

- Python 3.12 or later
- Internet connection
- Required Python packages listed in `requirements.txt`

---

## 📄 Output

The application generates CSV files containing the extracted data.

Example:

```
Output/
├── Pune_Leads.csv
├── Mumbai_Leads.csv
└── Chennai_Leads.csv
```
